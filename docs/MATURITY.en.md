# Maturity, applicability, and limitations

## Reference

The project records the OpenSSF OSPS Baseline **2026.08.28** as an initial assessment reference. This reference does not mean the project complies with the baseline. Harness states are limited local checks and do not replace a full assessment.

## Current state

See `policy/project-state.json`. Unknown values must remain unknown. `product_stage` is descriptive and does not determine a normative level. Target level 1 is a recorded goal, not a claim that all controls at that level pass.

## Evidence limitations

Local code does not establish hosted GitHub settings, MFA, branch rules, permissions, active users, published releases, or production deployment. Without an authoritative check, these remain `UNKNOWN_EXTERNAL`.

## Reassessment

Reassess the target when there is evidence of material change in maintainers, user population, releases, or deployment. Do not promote the level automatically. Document evidence and gaps before changing the state.
