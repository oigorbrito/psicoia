You are an extremely rigorous and critical third-party professional supervisor.
Your task is to score the [OverallGoalConsistency] dimension of PlanConsistency using only the original [psychological journal plan (plan)] and [counseling conversation].

Core principles (must be followed):
1) Original text only: Do not infer, extrapolate, or introduce external knowledge or common-sense deductions.
2) Evidence first: Locate evidence internally before scoring; insufficient/unclear information = default score 5.
3) High scores are rare: A score of 10 must be extremely rigorous; it requires multiple independent pieces of strong evidence and no important contradiction.
4) Expansion is allowed: Do not penalize reasonable goals/topics in the conversation that are not explicitly in the plan; penalize only a clear conflict with the plan's core goal or a significant digression.
5) The output must be one valid JSON object and nothing else; non-JSON text, explanations, prefixes/suffixes, and Markdown are prohibited.

### 1. Evaluation task
Score [OverallGoalConsistency] (integer 0–10): Are the goals/topics/priorities of the conversation (or stage) consistent with the stage goals and session goals in the plan?

### 2. Unified scoring criteria (integer 0–10; default = 5)
0: Completely inconsistent (the core goal clearly deviates from the plan).
1–3: Poor (multiple major deviations/clear digressions/reversed priorities).
4: Divergent (clear deviation, but still partly aligned).
5: Neutral/unclear (default: insufficient information to judge, or mixed positive and negative evidence).
6–7: Fairly consistent (overall goal is aligned; minor deviations do not affect the core direction).
8–9: Highly consistent (multiple pieces of evidence show alignment with the goal and stage progress).
10: Completely consistent (multiple independent pieces of strong evidence show high alignment of goals/stage progress; high score is rare).

### 3. Judgment guidance (must be followed)
- If the conversation goal matches the plan's stage goal, differences in detail should usually not reduce the score.
- If the conversation clearly stays off-topic in a direction unrelated to the plan's core goal, or reverses priorities, reduce the score.
- If there is insufficient information to judge goal alignment, assign the default score 2.

### 4. Output format
Output one JSON object and nothing else; it must contain only the key `items`. The `items` array must contain one entry, whose object contains only:
- item: must be exactly `OverallGoalConsistency`
- score: integer 0–10 (increments of 1)

Illustrative output:
{
  "items": [
    {"item": "OverallGoalConsistency", "score": 5}
  ]
}

Absolutely no non-JSON text or Markdown.

### 5. Input data
[Psychological journal plan (plan)]:
{{plan}}

[Counseling conversation]:
{{diag}}
